## 2. E0–E5 的实际含义

E0 是共同基线，E1–E5 是五个受控机制实验，因此“另外五个实验差异接近”是相对于同一 E0 比较。

| 变体 | 实际机制 | 基底/修正方式 |
|---|---|---|
| E0 | 原始归一化 CLIP prototype cosine classifier | 无额外 C1 修正 |
| E1 | 静态低秩对称度量 | `B_sem`；上下文输入被置零 |
| E2 | 上下文自适应低秩对称度量 | `B_sem` |
| E3 | 上下文自适应类别 logit 修正 | 零均值动态 logit correction |
| E4 | 上下文自适应公共二维平面旋转 | `B_sem` |
| E5 | 上下文自适应低秩对称度量的原型平面对照 | `B_proto`，不能称为语义基底 |

所有变体使用相同 backbone、数据协议、三 seeds、训练轮数和 target-best 规则。

需要保留一个执行层限制：Session 1 和 Session 2 分别由不同组员、不同 GPU/环境运行，因而绝对的 session 差异与执行环境存在混杂，不能仅凭 69.3% 对 75.9% 判断 session 难度。好在每个 session 内的 E0–E5 都在该组员同一环境中完成，因此本文优先使用同一 session-target-seed 内的配对差；这种设计能降低但不能完全消除跨环境复现风险。

## 7. 对论文的直接判断

### 当前数据可以支持

1. C1 五种机制均已正确实现并产生非零作用，不是失效模块。
2. 在已完成的 Session 1–2 中，E3 的平均结果最高，并在两个 session 中方向一致。
3. 低秩语义度量 E2 只有很小的正向均值；静态度量 E1 几乎与 E0 相同。
4. `B_proto` 对照 E5 没有优于 E0，当前均值反而低 0.343 个百分点。
5. 当前结果更像“不同上下文修正形式的受控消融”，而不是已经建立显著性能提升的新 SOTA 证据。

### 当前数据不能支持

1. 不能写“E3 显著优于 E0”；当前 CI 跨 0，校正后 p=1.000。
2. 不能写“语义低秩度量显著有效”；E2 仅 +0.179 pp，证据不稳定。
3. 不能因 E5 较低就声称 `B_sem` 已被证明具有独立语义优势；还需完整 Session 3 和更直接的配对机制检验。
4. 不能把 90 runs 当成 90 个独立被试做显著性检验。
5. 不能把 target-best accuracy 写成独立测试集泛化性能。
6. 不能在 Session 3 未完成时把本表称为正式完整 C1 主表。
7. 不能忽略 session 与组员硬件/软件环境绑定的限制；跨 session 绝对均值需谨慎解释。

## 8. 论文策略建议

如果 C1 是论文唯一核心创新，当前证据偏弱：最大增益只有 +0.344 pp，且不确定区间跨 0。仅通过措辞包装不能解决证据强度问题。

更稳妥的组织方式是：

- 把 E0–E5 定位为机制级消融与诊断，而不是每一项都必须显著提高 accuracy；
- 等 Session 3 完成后冻结完整主表，再进行相同的 subject-cluster 配对分析；
- 将 E3 作为当前候选，因为它跨两个 session 方向一致、机制作用最强；但在完整结果前只称“numerically best”；
- 若论文主贡献还包括 C2 的负迁移控制、source routing 或其他主模型收益，应让那些独立证据承担主要贡献，C1 用于说明何种上下文修正更可行；
- 若 Session 3 后 E3 仍只有约 0.3 pp 且区间跨 0，应诚实写成有限或不确定收益，并讨论为什么强 backbone 下额外度量只改变少量边界样本；
- 不应在看到当前结果后重新调 tau、rank、gamma 再把同一 45-fold 数据作为确认结果。任何新调参必须注册为新配置并单独验证。
